# implement-spec-v3 采用单向测试隔离

2026-11-01，用户确认 v3 保留测试判据独立于实现，允许实现者读取当前独立测试；测试作者、测试审查者和独立测试修复者始终不接触实现。这样同一套测试可以直接驱动小步 TDD，减少双盲反馈中的运行与诊断交接；双盲也能先测后写，本次取舍并非认定它无法实现 TDD。

这一选择放弃对实现者隐藏具体用例，接受实现可能针对有限用例优化的风险，由独立判据、覆盖审查与最终验收共同约束；实现者仍无权直接修改独立测试判据。该信息边界决定后续角色上下文与测试交接方式，测试一旦公开也不能靠恢复一条规则重新隐藏，因此单独记录；分阶段资格见 [ADR-0002](0002-stage-test-qualification.md)，完整流程见[方案](../plans/implement-spec-v3.md)。
